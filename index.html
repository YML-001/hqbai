03 四条流程

问答

  1. 1. 打开页面，可以不登录。
  2. 2. 提问后只查已审核知识库。
  3. 3. 查到了就回答，并给出这一端的入口。
  4. 4. 没查到就说暂未收录，并给出热线。

办事跳转

  1. 1. 先看清单里有没有当前端口的地址。
  2. 2. 有地址就确认后离开助手。
  3. 3. 水电缴费在电脑上只出二维码。
  4. 4. 仅电脑事项在手机上展示地址。没有地址就只说明。

会议提醒

  1. 1. 录入主题、时间、地点和有工号的人。
  2. 2. 保存即生效，本期不审批。
  3. 3. 默认会前 1 小时，可按单场改短。
  4. 4. 经 ITS 按工号推送一次。取消后不再推送。

知识审核

  1. 1. 维护人起草，公开和内部分开标记。
  2. 2. 提交后由另一人审核。
  3. 3. 通过才发布，前台才能引用。
  4. 4. 退回就修改。已发布的可以下线。
